## 项目内容

网站用于展示个人介绍、项目经历、作品和数据图表，不再只是模板博客，而是围绕简历和项目证据建立的数字档案。

## 工程实现

- 使用 Astro、TypeScript、Tailwind CSS 和 Canvas 2D。
- 实现搜索、RSS、Sitemap、响应式布局和轻量动画。
- 通过 GitHub 与 Vercel 完成线上部署和自动构建。
- 使用 Pagefind 生成静态搜索索引。

## 量化结果

- 16+ 页面/路由，11 个核心组件。
- 首页 Lighthouse 性能最高 99，其余指标 100；CLS=0。
- 当前已完成个人简历和 7 个核心项目的初步填充。
