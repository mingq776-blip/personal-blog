## 研究设计

选取大雁塔（砖石）和应县木塔（木构）两座古建进行对照建模，统一朝向和平原环境，设计环境应力、病害标签和结构稳定性观测节点。

## 实验与结果

- 使用 Minecraft Java 1.20.1、Fabric Loader 0.19.3 和 JDK 17。
- 完成 20,000 游戏日环境模拟。
- 观察苔藓、积雪、沙化标签共现和结构完整性。
- 大雁塔苔藓覆盖率南向 35%、北向 12%；木塔柱根 41%、斗拱 28%。
- 20,000 日后无方块丢失或坐标偏移，暂估结构完整率 100%。
